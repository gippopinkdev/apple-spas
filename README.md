# Яблочный спас

Интерактивный сайт проекта "Яблочный спас" — карта одномандатных округов с карточками кандидатов, которые поддерживают мирную политическую повестку.

## О чём проект

Это гражданская и политическая информационная платформа. Главная идея: показать, что в одномандатных округах есть кандидаты, поддерживающие мир и общественный диалог, и дать пользователю удобный способ найти их по карте.

Основные фичи:

- На главной странице расположена интерактивная карта;
- пользователь кликает на округ и видит кандидата для этого округа, если он есть;
- в боковой панели выводятся информация о кандидате, его регионе, партии и ссылках;
- На странице "О нас" расположена общая информация о проекте;

## Внеси свой вклад в проект

Проект открыт для участия, и особенно полезны правки в следующих направлениях:

- улучшение данных о кандидатах и округах;
- распространять проект
- улучшение UX на мобильных устройствах;
- доработка карты и логики выбора округа;
- улучшение UI
- добавление новых фичей (например, возможность поиска по адресу).
- пользоваться отдельными частями данного проекта (наример, картой, разбивкой по округам)

## Участникам

У проекта есть чёткая цель — поэтому даже небольшая правка, которая делает карту или информацию удобнее и помогает распространять проект, уже имеет ценность.

## Что находится в репозитории

- `src/app/` — маршрутизация и общий shell приложения;
- `src/pages/` — страницы Home, About, District, Candidate;
- `src/features/map/` — интерактивная SVG-карта и логика drag/pan/zoom;
- `src/features/candidates/` — карточка кандидата и панель с информацией;
- `src/data/` — загрузка campaign data и соединение UI с JSON-данными;
- `public/` — статические данные: `districts.json`, `candidates.json`, SVG-карта и другие ресурсы;
- `src/styles/` — общие стили, layout и мобильная адаптация.

## Технический стек

- React 19
- React Router DOM 7
- Vite 8
- Vanilla CSS
- статические JSON-данные вместо бекенда

## Как запустить проект локально

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Запустите локальный dev-сервер:

   ```bash
   npm run dev
   ```

3. Откройте адрес, который покажет Vite в терминале, обычно это `http://localhost:5173`.

4. Для проверки сборки:

   ```bash
   npm run build
   ```

5. Для локального предпросмотра собранной версии:

   ```bash
   npm run preview
   ```

## Рекомендуемый рабочий процесс для этого репозитория

1. Сделайте форк проекта или локальную ветку.
2. Запустите приложение командой `npm install` и `npm run dev`.
3. Найдите область, которую хотите улучшить:
   - данные `public/*.json`;
   - код карты;
   - стили;
   - карточка кандидата;
   - маршрутизация и контент.
4. Внесите минимальные правки и проверьте, что всё работает через `npm run build`.
5. Если вы меняете UX карты, обязательно убедитесь, что зум и перетаскивание карты продолжают работать.
6. Оформите PR с описанием, что именно изменено и зачем.
